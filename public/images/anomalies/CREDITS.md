# Anomaly reference photographs

These category-level reference photographs illustrate the frontend's mock detections. They are not survey captures, sonar returns, or evidence about the locations/IDs shown in SonarSense. No NOAA endorsement is implied. Files are downloaded JPEGs with no content edits; the UI scales them with `object-fit: contain`.

Retrieved September 3, 2026. NOAA Ocean Exploration's [FAQ](https://oceanexplorer.noaa.gov/faqs/) and [multimedia policy](https://oceanexplorer.noaa.gov/about/kit-specs/) allow reuse of website media unless otherwise noted, with the original credit. The selected Ocean Exploration pages carry no copyright exception. NOAA National Marine Sanctuaries' [media policy](https://sanctuaries.noaa.gov/news/media/) covers NOAA-created photographs; the Norvana photo is explicitly credited to Hoyt, NOAA. The Commons file explicitly identifies its NOAA image as public domain.
